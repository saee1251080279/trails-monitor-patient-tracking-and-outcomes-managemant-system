# Trails Monitor Hub

Doctor-facing fictional patient monitoring MVP built with React, TanStack Start, Tailwind v4 and Lovable Cloud.

## Run

```sh
npm install
npm run dev
```

Use the Cloud connection generated by Lovable. Database schema and fictional seed rows are in `drizzle/migrations`. Do not commit private credentials.

## Included

- Enrollment, live name/ID filtering, queue selection, queue progression, validated enrollment and editing.
- Simulated vitals, illustrative organ assessment, trend charts and sample blood values.
- Sample report previews and text downloads, saved appointments with cancellation, saved remarks with editing and deletion.
- Saved doctor name/photo fields and owner-scoped access to patient, appointment and remark records.
- Accessible dialogs, inline errors, toasts and responsive layouts.

## Assumptions and limitations

- No reference screenshots were attached, so layout follows the written blue/grey/sky-blue three-column specification.
- Lovable Cloud replaces the requested separate Express/SQLite server; the app stays on the supported TanStack platform.
- The initial screen offers a read-only fictional workspace preview; Doctor sign in opens Tap to Start and login. Writes require a real Cloud session.
- Only fictional sample values are used. Vitals are simulated, not persisted sensor readings. Reports are illustrative text, not actual scans. Diagnostic history is sample content.
- This is not a clinical application and does not establish HIPAA/DPDP compliance.
- No signup, real devices, websockets, billing, video calls, push notifications, multi-doctor roles or AI.
